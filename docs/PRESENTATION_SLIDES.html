BACKGROUND & MOTIVATION

Problem Statement & Industry Context

1. Automated ATS Filtering
  • Over 75% of candidate resumes are filtered out by automated ATS before human recruiter review.
  • Students lack feedback on missing technical keywords, poor formatting, and unparsed tables.
  • Generic resumes fail to showcase project metrics and measurable outcomes.
2. Interview Practice Void
  • Students experience intense anxiety during on-campus technical and HR placement interviews.
  • Limited access to expert senior interviewers for personalized feedback.
  • Subjective evaluation without multi-criteria scoring rubrics.
3. Fragmented Ecosystem
  • Students juggle separate platforms for DSA (LeetCode), roadmaps (YouTube), and job boards.
  • No single metric tracks overall "Placement Readiness Index" (0–100%).
  • College placement cells lack visibility into candidate readiness.

ENGINEERING ARCHITECTURE

Full-Stack System Architecture

Frontend (Vite + React)
  • React 18 Single Page Application with Tailwind CSS 3.4.
  • Axios client configured with withCredentials: true.
  • Client routing secured by ProtectedRoute & AdminRoute.
  • Interactive circular SVG gauges, category progress bars, and timed quiz palettes.
Backend (Express & Node.js)
  • RESTful modular API (Controllers, Middleware, Routes, Validators).
  • Token retrieval from HttpOnly cookies with Bearer header fallback.
  • Multer file streaming + pdf-parse sanitization.
  • Dedicated authLimiter blocking brute-force attacks.
Database & AI Engine
  • MongoDB with Mongoose ODM modeling 10 distinct collections.
  • Bcrypt password hashing (10 salt rounds) in pre-save hooks.
  • Google Gemini 1.5 Flash official SDK integration.
  • Disk cleanup on resume deletion to prevent storage leaks.

SECURITY & RBAC

Enterprise Security & Authentication Architecture

HttpOnly Cookie Sessions
  • Zero Long-Lived Tokens in localStorage: JWT is delivered strictly in HttpOnly, SameSite cookies with path /.
  • XSS Mitigation: Client JavaScript cannot read the token, neutralizing XSS exfiltration risks.
  • Dual Token Acceptance: Middleware inspects cookies first, falling back to Bearer tokens for test suites and scripts.
  • Session Termination: Logout endpoint clears cookie with Expired timestamp (1970-01-01).
Privilege Defense & Hardening
  • Bcrypt Password Encryption: 10 salt rounds in pre-save hooks; plain text never stored.
  • select: false: Password field is excluded from queries by default.
  • Privilege Defense: Public registration strictly enforces role: 'student'. Users cannot grant themselves admin status.
  • Rate Limiting: authLimiter caps auth requests to 25 / 15 min to prevent credential brute-forcing.
